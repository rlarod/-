# 커뮤니티 살리기 — 실행 계획

**작성** 2026-08-24 · PM
**지시** 대표 — "커뮤니티를 어떻게 살릴까 고민중이야. 국내 유명 커뮤니티 직접 보고
판단해서 계획이랑 구도 짜고 바로 실행할 수 있는 수준으로"

---

## 1. 지금 우리 게시판은 어떤 상태인가

| | |
|---|---|
| 회원 | **4명** (곧 2명으로 정리 예정) |
| 글 | **4개 수준** |
| 화면 | 제목 · 글쓴이 · 추천 · 댓글 · 조회 · 작성시간 |
| 비회원 열람 | ✅ 됨 (`schema-guest-read.sql` 로 이미 열려 있음) |
| 인기글 칸 | **있는데 꺼져 있음** — `index.html:661` `display:none` |
| 계급장 | 댓글·채팅·랭킹엔 붙는데 **글 목록엔 안 붙음** |

**빈 방입니다.** 들어와도 볼 게 없습니다.

---

## 2. 국내 커뮤니티를 직접 열어 본 것

### 디시인사이드 (비트코인 갤러리)

```
탭:    전체글 | 개념글 | 공지
목록:  번호 · 제목[댓글수] · 글쓴이 · 작성일 · 조회 · 추천
글쓴이: 고정닉이면 갤로그 아이콘, 아니면 IP
```

**배울 점** — **개념글 탭.** 추천을 일정 수 이상 받은 글만 따로 모읍니다.
글이 아무리 많아도 **"볼 것"이 항상 정리되어 있습니다.**

### 에펨코리아 (가상화폐)

```
상단:  포텐 터짐 (최신순 / 화제순) — 목록 위에 따로
분류:  쇼핑/투자 > 핫딜 · 주식 · 가상화폐 · 부동산
```

**배울 점** — 디시의 개념글과 **같은 원리**를 이름만 바꿔 씁니다.
좋은 글을 위로 끌어올리는 장치는 **어느 커뮤니티에나 있습니다.**

### 네이버 종목토론실

**배울 점** — **종목이 방을 만듭니다.** 사람이 주제를 안 만들어도
"삼성전자"라는 대상이 있으면 글이 저절로 생깁니다.

---

## 3. 그래서 무엇이 문제인가

커뮤니티 운영 자료들이 공통으로 말하는 것은 하나입니다.

> **초기 커뮤니티는 운영자가 직접 콘텐츠를 채워야 한다.**

그런데 우리는 **직접 안 써도 됩니다.**

> ## ⭐ 우리에겐 남들에게 없는 게 있습니다 — **거래 자체가 콘텐츠입니다.**
>
> 오늘(8/24) 김갱님 거래 **7건**이 이미 채팅에 자동으로 올라왔습니다.
>
> ```
> 김갱님이 BTC 매도 포지션을 +116,631,862원 익절했습니다
> 김갱님의 BTC 매수 포지션이 강제청산되었습니다 (-338,235,972원)
> ```
>
> **이게 사라지고 있습니다.** 채팅은 흘러가 버립니다. 게시판에 남으면 콘텐츠가 됩니다.

일반 커뮤니티는 사람이 글을 써야 돌아갑니다.
**우리는 거래만 하면 글이 쌓입니다.** 이걸 안 쓰고 있는 게 지금의 문제입니다.

---

## 4. 실행 계획 — 순서대로

**게시판을 나누지 않습니다.** 회원 4명에 방을 나누면 전부 빈 방이 됩니다.
**나누지 말고 채웁니다.**

---

### 1단계 · 글 목록에 계급장 (가장 쉬움)

**왜** — 지금 댓글·채팅·랭킹엔 계급장이 붙는데 **글 목록에만 없습니다.**
누가 쓴 글인지 한눈에 안 보입니다. 디시의 고정닉/갤로그 자리입니다.

**어디** — `js/rank-badge-attach.js:140`

```js
var targets = ["leaderboard-body", "chat-messages", "board-comments-list"];
                                                  // ← "board-list-body" 추가
```

**규모** — 한 줄. 이미 있는 장치를 한 곳 더 가리키는 것뿐입니다.

**주의** — 지금 댓글에 배지가 **두 개씩** 붙는 버그가 있습니다(TL-012).
그것부터 고치고 이걸 합니다. 안 그러면 글 목록에도 두 개가 붙습니다.

---

### 2단계 · 거래를 글로 자동 등록 ⭐ **이게 핵심입니다**

**왜** — 매일 글이 저절로 쌓입니다. 아무도 안 써도 게시판이 안 죽습니다.

**어디** — `js/trade-events-chat.js` 를 그대로 본떠 **`js/trade-events-board.js`** 를 새로 만듭니다.

그 파일은 이미 이렇게 하고 있습니다:
- 포지션이 **실제로 청산됐을 때만** 동작 (주문 버튼 눌렀다고 X)
- 청산 시각으로 중복을 막음
- `chat_messages` 에 직접 insert — **`chat.js` 를 안 건드림**

같은 방식으로 `posts` 에 넣으면 됩니다.

**도배를 막는 장치가 반드시 필요합니다.**

| 조건 | 값(제안) |
|---|---|
| 최소 손익 | 절대값 **1,000만원 이상**만 글로 |
| 하루 상한 | 회원당 **5건** |
| 그 아래는 | 지금처럼 채팅에만 |

**글 모양(제안)**

```
제목:  [거래] 김갱님이 BTC 매도로 +1억 1,663만원
본문:  방향    매도(숏)
       진입가  77,530.70
       청산가  76,204.10
       레버리지 10배
       보유    1시간 19분
       손익    +116,631,862원 (+7.4%)
```

**주의 — 회원이 싫어할 수 있습니다.** 손실 거래까지 자동으로 글이 되면
기분이 나쁠 수 있습니다. **손실 거래를 글로 남길지는 대표 판단이 필요합니다.**
(채팅에는 이미 손실도 올라가고 있습니다)

---

### 3단계 · 인기글 켜기 (디시 개념글 / 에펨 포텐)

**왜** — 글이 쌓이기 시작하면 **볼 것을 골라줘야** 합니다.
2단계로 자동 글이 늘면 좋은 글이 묻힙니다.

**어디** — `index.html:661` 의 `#board-popular-section` 이 **이미 있는데 꺼져 있습니다.**

```html
<div id="board-popular-section" style="display:none;">
  <div class="board-section-title">🔥 인기글</div>
```

**기준(제안)** — 회원이 4명이니 추천 기준을 낮게 잡아야 합니다.

| 회원 수 | 인기글 기준 |
|---|---|
| ~10명 | 추천 **2** 이상 |
| ~50명 | 추천 5 이상 |
| 그 이상 | 추천 10 이상 |

**규모** — 켜는 것 자체는 작습니다. 다만 `js/board.js` 가 **수정 금지 파일**이라
별도 모듈로 우회해야 합니다.

---

### 4단계 · 글에 "매수 / 매도" 의견 붙이기 (종토방)

**왜** — 네이버 종토방의 핵심입니다. 글을 안 읽어도 **분위기가 보입니다.**
그리고 나중에 **"누가 맞췄나"** 를 셀 수 있습니다 — 우리 사이트에만 가능한 것입니다.

**어디**
- `posts` 표에 `opinion` 칸 추가 (`long` / `short` / `null`)
- 글쓰기 화면에 버튼 2개
- 목록에서 초록 `매수` / 빨강 `매도` 표시

**⚠️ 색 규칙 주의** — 확정 팔레트상 **빨강은 손익 표시에만** 씁니다.
의견 표시에 빨강을 쓸지는 따로 정해야 합니다.

**나중에 할 수 있는 것** — 글 쓴 뒤 24시간 가격과 대조해 **적중률**을 계급장 옆에 붙입니다.
이건 종토방이 못 하는 것입니다. 우리는 가격 데이터를 갖고 있습니다.

---

### 5단계 · 회원이 늘면 그때 나눈다

**지금 나누지 않습니다.** 아래 정도가 되면 그때 봅니다.

```
회원 30명 이상  +  하루 글 10개 이상   →  게시판 분리 검토
```

---

## 5. 하지 않을 것

| | 왜 |
|---|---|
| **게시판 나누기** | 회원 4명. 전부 빈 방이 됩니다 |
| **가짜 글·봇 계정** | 회원을 속이는 것입니다. 하지 않습니다 |
| **회원 수 부풀리기** | 같은 이유 |
| **자동 글에 가짜 숫자** | 실제 거래 기록만 씁니다 |

---

## 6. 순서 요약

```
0단계  TL-012 댓글 배지 중복 고치기        (이미 배정됨)
1단계  글 목록에 계급장                     한 줄
2단계  거래를 글로 자동 등록 ⭐             새 모듈 1개
3단계  인기글 켜기                          우회 모듈
4단계  글에 매수/매도 의견                  SQL + 화면
5단계  (회원 30명 넘으면) 게시판 분리
```

**2단계가 전부입니다.** 나머지는 2단계가 만들어낸 글을 잘 보이게 하는 장치입니다.

---

## 7. 대표 결정이 필요한 것

| 항목 | 왜 물어보나 |
|---|---|
| **손실 거래도 글로 남길지** | 회원이 기분 나쁠 수 있음. 채팅엔 이미 올라감 |
| **자동 글 기준 금액** | 1,000만원 제안. 낮으면 도배, 높으면 글이 안 쌓임 |
| **의견 표시에 빨강 쓸지** | 확정 팔레트상 빨강은 손익 전용 |

**이 셋은 밤새 진행하지 않고 아침에 여쭙습니다.**
1단계·3단계는 결정이 필요 없으므로 먼저 진행할 수 있습니다.
