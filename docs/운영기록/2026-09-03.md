## 고침 — 놓친 교차 되찾기

종목을 옮겼다 돌아오면(창을 닫았다 열어도) **그 사이 봉의 고가·저가를 훑어** 알람가를
지났는지 봅니다. 지났으면 **늦은 알림**으로 구분해 알립니다.

```
알림줄    늦은 알림 — 비트코인 76,343.00 를 09-02 19:50 에 지났습니다 (자리를 비운 사이)
이름표    알람 울림(늦음)     ← 지금 울린 것은 "알람 울림"
소리      587Hz 세 번          ← 지금 울린 것은 880Hz 두 번
```

**일부러 놓치는 것** — 자리를 뜬 그 순간에 걸쳐 있던 봉은 안 봅니다. 세면 **알람을 걸기 전에
이미 지나간 값**을 지금 지난 것처럼 알립니다. **헛알람보다 봉 하나 못 잡는 쪽**을 골랐습니다.

**헛알람 없음도 쟀습니다** — 최근 30분 고가+3,000 / 저가−3,000 두 개로 같은 절차를 돌려
25개 봉을 훑고 **둘 다 안 울림, 알림줄 0건.**

# 🟠 [P2] fx 지표 패널이 화면 밖으로 잘림 — 조사팀이 원인 확정

**PM 과 점검팀의 측정이 달라 배정하지 않고 조사팀에 넘겼습니다.**

## 결론 — 둘 다 정확히 쟀고, ★스크롤 위치★ 가 달랐습니다

```

          scrollY 560  패널 943px · 넘침 ★+318★ · 추가버튼 안 보임 ← 점검팀 값
```

**1px 차이로 갈립니다** — y=560 에서 아래 여유 544, 열 때 높이 543.

## 원인 (확신도 확실)

`js/chart-indicator-menu.js:552 open()` 이 **기본 7줄만 있는 상태에서 자리를 확정**하고,
나머지 줄과 "+ 지표 추가" 는 **그 뒤 관측자를 통해 들어옵니다.** `place()` 를 다시 부르는

**결정적 증명** — 그 상태에서 창 크기 신호 하나만 던져 다시 재게 하니
`943px / 넘침 +140 / 안쪽스크롤 0` → `631px / 넘침 −260 / 안쪽스크롤 253`.
**계산 로직은 멀쩡하고 한 번 더 안 불릴 뿐입니다.**
