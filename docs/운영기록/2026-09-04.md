# 배포 · `0daf319` 색 봉인이 "색"이 아니라 "여섯 글자"를 보던 것

감사팀이 찾았습니다. 정규식이 `#[0-9A-Fa-f]{6}` 하나뿐이라 **같은 색인데 표기만
바꾸면 통과**했습니다.

```
"rgb(91,156,246)"  초록 통과   ← 트레이딩뷰 링크색 #5B9CF6 과 같은 색
"#5AF"             초록 통과   ← 3자리 hex
"#5B9CF6"          빨강        ← 6자리만 잡음
```

# 게이트 2 재심 — 폰 지표 제한 (수리팀 · 반려분 수정)

## ⚠️ PM 이 짚은 원인이 틀렸습니다

PM 은 `js/chart-indicator-kit.js:3148` 의 `hasAttribute` 오류를 원인으로 짐작했는데,
**그 줄은 이미 지워져 있었고 오류도 안 났습니다.**

**진짜 원인** — 수리팀이 그 오류를 피하려고 고른 우회 방법 자체였습니다.
`removeAttribute` 가 테스트의 가짜 DOM 에 없어서 **지우는 대신
`data-kit-rest="0"` 을 넣었고**, 그래서 **쉬지도 않는 칩 전부에 속성이 눌러 붙었습니다.**

## ⚠️ PM 의 측정 해석도 정확하지 않았습니다

PM 이 **"쉼 표시가 7개 보인다"** 고 적었는데, **화면에 "쉼" 글자가 실제로 뜬 것은
아니었습니다.** `[data-kit-rest]` 속성이 붙은 칩 중 "보이는 것" 을 센 값이고,
그건 **칩이 보인다는 뜻이지 "쉼" 글자가 보인다는 뜻이 아닙니다.**

**다만 결함은 맞았습니다** — 수리팀도 "남의 눈에 '멀쩡한 것까지 쉬는 중' 으로
읽히는 흔적을 남긴 것 자체가 결함" 이라고 인정했고 반려가 맞다고 했습니다.

## 고친 방법 — ★구조로 막았습니다★

속성 → **클래스**(`.tl-kit-rest`). 안 쉬면 흔적이 아예 안 남습니다.
그리고 **붙이는 곳과 떼는 곳을 한 줄로** 합쳤습니다:
```js
var want = rest ? "tl-kit-btn tl-kit-rest" : "tl-kit-btn";
```
**떼는 갈래가 따로 없으니 "떼기만 안 도는" 상태가 만들어질 수 없습니다.**
PM 이 지적한 "켜는 코드는 있는데 끄는 코드가 안 돈다" 를 **구조로** 막은 것입니다.
