## 1. 집 PC 에서 처음 할 것 (순서대로)

### ① 클로드 코드 설치하고 로그인

회사에서 쓰던 것과 **같은 계정**으로 로그인합니다.

### ② 저장소 받기

```bash
git clone https://github.com/rlarod/-.git trading-league
cd trading-league
```

### ③ ⚠️ 줄바꿈 설정 — 이거 안 하면 테스트가 전부 깨집니다

윈도우 Git 이 줄바꿈을 자동으로 바꿔버려서 **수정 금지 파일 12개가 전부 "변경됨"으로
보입니다.** 실제로 이것 때문에 테스트가 무더기로 실패한 적이 있습니다.

```bash
git config core.autocrlf false
git rm --cached -r . -q
git reset --hard
```

`.gitattributes` 를 넣어둬서 재발하지 않지만, 안전하게 한 번 돌려두면 좋습니다.

### ④ 확인

```bash

npm test
```

**87개 파일이 전부 통과하면 정상입니다.** 하나라도 실패하면 ③번을 다시 하세요.

### ⑤ 클로드에게 이 한 줄만 던지면 됩니다

```

```

### ① · ② 지갑 초기화 (둘 다 돌려야 합니다)


돌린 뒤 **잔고가 100,000 보다 많은 상태에서 지갑 초기화 버튼을 눌러**
경고 창이 뜨는지 캡처 한 장 주시면 확정됩니다. (창 뜨면 **취소** 눌러도 됩니다.)

**다만 수리팀이 중간에 멈춘 파일이라 게이트 2 를 완전히 못 돌렸습니다.**

**리그가 비어 있다는 걸 광고하는 꼴**이 됩니다.

## 7. ⚠️ 오늘 겪은 함정 (집에서 또 겪지 마세요)

### 브라우저가 계속 죽는 이유

`timeout` 으로 끊었다고 생각한 명령이 **안 죽고 배경에서 계속 돌면서 브라우저를
새로 띄우고 창 크기를 기본값(1264)으로 되돌려 놓습니다.**
360 으로 재는 중에 값이 이상하게 나오면 이걸 의심하세요.

- **`reload` 를 쓰지 마세요. 페이지가 죽습니다. 다시 열 때는 `open`**
- **`agent-browser close --all` 금지.** 다른 팀 세션까지 전부 닫힙니다
- 캡처·측정 뒤에는 **창 폭과 값을 같이 읽어** 확인하세요

자세한 것은 `CLAUDE.md` 의 "브라우저가 계속 죽는 진짜 원인" 항목.

### `git add index.html` 조심

**여러 팀이 같은 `index.html` 을 씁니다.** 통째로 담으면 남의 미완성 작업이
같이 올라갑니다. 오늘 두 번 그랬고 한 번은 라이브까지 나갔습니다.
**팀이 몇 행에 무엇을 넣었는지 확인하고 그 줄만 올리세요.**

### 로컬 서버가 몇 시간 돌면 죽습니다

`npm run dev` 가 `EMFILE` 로 죽습니다. 브라우저 작업 전에 살아있는지 확인하세요.

```bash
timeout 10 curl -s -o /dev/null -w "%{http_code}" http://localhost:3000
```
