## ⭐ 오늘 확정된 것 — 다시 조사하지 마세요

### 청산 알림 중복 — 전제가 틀렸습니다

**"어제 알림이 오늘 다시 나갔다" 가 아닙니다.** 조사팀이 실행으로 확인했습니다.

`js/trade-events-chat.js:101` 의 `이번접속거래인가()` 가 **"이번 접속 이후 청산된 것"만**
통과시킵니다. 어제 거래는 시각이 오래돼 무조건 걸러집니다.
**`chat-event-seen` 저장소는 이 건과 무관합니다. 그걸 고치면 헛수고입니다.**

**즉 09:44 에 강제청산이 실제로 한 번 더 일어났습니다.** 갈래가 둘입니다.

| | 무엇 | 등급 |
|---|---|---|
| **(A)** | 어제 청산 뒤 서버 `positions` 에 유령 행이 남아, 로그인 첫 시세에 재청산 | **P1 버그** |
| **(B)** | 대표가 오늘 무료충전 받고 다시 100배 최대치로 걸었다가 청산 | 버그 아님 |

**금액이 똑같은 것은 두 경우 다 정상입니다.** 본부장이 검산했습니다 —

```
잔고 100,000 USDT → 100배 최대 증거금 = 100,000 / (1 + 100 × 0.0005) = 95,238.095
                  → × 1500 = 142,857,142.857 → 142,857,143원
신고된 금액                                    -142,857,143원   ✓
```

**"잔고가 정확히 10만 달러일 때 100배 최대치"의 고정값**이라 언제 걸든 같은 문장이 나옵니다.

**가르는 법 — 대표에게 물어보면 SQL 없이 즉시 갈립니다.**
> "오늘 로그인하고 직접 주문을 넣으셨나요?"
> 넣었다 → (B) 버그 아님 / 안 넣었다 → (A) P1, 다음 로그인 때 또 터짐
