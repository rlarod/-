## ⚠️ 본부장 정정 — "0.4% 여야 150배가 성립한다" 는 틀렸습니다

본부장이 대표에게 이렇게 보고했습니다 —

> 150배(증거금 0.667%)가 성립하는 **유일한 조합**이라 0.4% 를 전 종목에 씁니다

**틀렸습니다.** 조사팀이 잡았습니다. 조건은 `1/배율 > 유지증거금률` 입니다.

```
150배 → 개시증거금 0.6667%
  0.5% → 0.6667% > 0.5%   성립 ✅   버티는 폭 0.167%
  0.4% → 0.6667% > 0.4%   성립 ✅   버티는 폭 0.268%
```

**지금 0.5% 로도 150배는 됩니다.** 즉시 청산이 시작되는 지점은 0.5% 에서 200배입니다.

**0.4% 의 진짜 근거는 "바이낸스가 BTCUSDT 150배 구간에 실제로 쓰는 값" 입니다.**
대표 결정(150배 통일)은 그대로 유효하지만, **논거를 바꿔서 다시 올려야 합니다.**

### 기존 포지션에 미치는 영향 (0.5% → 0.4%)

**롱은 모든 배율에서 유리합니다.** 청산가가 진입가에서 멀어집니다.
**숏은 4배 이상만 유리하고, 1·2·3배 숏은 아주 조금 불리해집니다.**

| 배율 | 숏 영향 |
|---|---|
| 1배 | 불리 0.149% |
| 2배 | 불리 0.065% |
| 3배 | 불리 0.024% |
| 4배 이상 | 유리 |

**즉시 청산되는 회원이 나올 수 있는 경우** — 숏 3배 이하이면서 현재가가
신규~기존 청산가 사이(폭 0.02~0.15%)에 있을 때만. **롱은 어떤 경우에도 아닙니다.**

**실제 명단은 못 셉니다.** `positions` 표에 RLS 가 걸려 있어 대표만 조회할 수 있습니다.
