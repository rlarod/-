### 나스닥 이름 — "나스닥" 으로 확정

본부장이 이렇게 보고했습니다 —

> 바이낸스에 있는 건 나스닥100 지수가 아니라 그 지수를 따라가는 **ETF(QQQ)** 입니다.
> 진짜 나스닥100 지수는 29,209 인데 QQQ 는 708 입니다. **약 41배 차이**입니다.
> "나스닥100" 이라고만 쓰면 회원이 708 을 보고 이상하게 여깁니다.

**대표 답 — "나스닥이라고만 하자".** 알고 내린 결정입니다.

**그래서 팀은 이렇게 씁니다.**

```
화면 이름     나스닥
심볼          QQQUSDT
❌ 쓰지 말 것  "나스닥100" · "NASDAQ 100" · "나스닥 지수"
              → 지수라고 부르면 숫자가 41배 안 맞습니다
```

**"지수" 라는 말을 붙이지 않는 것**이 이 결정의 핵심입니다.

## ⚠️ 본부장 정정 — "0.4% 여야 150배가 성립한다" 는 틀렸습니다

본부장이 대표에게 이렇게 보고했습니다 —

> 150배(증거금 0.667%)가 성립하는 **유일한 조합**이라 0.4% 를 전 종목에 씁니다

**틀렸습니다.** 조사팀이 잡았습니다. 조건은 `1/배율 > 유지증거금률` 입니다.

```
150배 → 개시증거금 0.6667%
  0.5% → 0.6667% > 0.5%   성립 ✅   버티는 폭 0.167%
  0.4% → 0.6667% > 0.4%   성립 ✅   버티는 폭 0.268%
```

**지금 0.5% 로도 150배는 됩니다.** 즉시 청산이 시작되는 지점은 0.5% 에서 200배입니다.

**0.4% 의 진짜 근거는 "바이낸스가 BTCUSDT 150배 구간에 실제로 쓰는 값" 입니다.**
대표 결정(150배 통일)은 그대로 유효하지만, **논거를 바꿔서 다시 올려야 합니다.**

## 조사팀이 확인한 것 (2026-08-27)

**바이낸스 공식 FAQ 예제 두 개를 원 단위까지 재현했습니다.**

```
바이낸스  롱: 진입가 × (1 − 1/배율) / (1 − MMR)
우리      롱: 진입가 × (1 − 1/배율 + MMR)      js/trading.js:398
```

식의 모양 차이는 아주 작습니다(150배·0.4%·10만에서 **1.07 USDT / 0.0011%**).
**진짜 차이는 유지증거금률(0.5% vs 0.4%)과 판정 가격입니다.**

| | 바이낸스 | 우리 |
|---|---|---|
| 유지증거금률 | 구간별 (BTC 1구간 0.4%) | 0.5% 고정 |
| 판정 가격 | **마크가격** | **최근 체결가** (`js/websocket.js:75`) |
| 수수료·펀딩비 | 지갑잔고가 변수라 청산가가 움직임 | 진입 시 한 번 계산하고 안 움직임 |

### `js/trading.js` 무수정으로 바꿀 수 있습니다 (실측 확인)

엔진이 `getSnapshot()` 과 `persist()` 에서 **살아있는 포지션 객체를 그대로 내줍니다.**
`pos.liq` 만 덮어쓰면 엔진이 따라옵니다. 4개 경로 전부 실제로 돌려 확인했습니다.

⚠️ **`App.Storage.save` 감싸기가 반드시 있어야 합니다.**
지정가 체결 경로에서 `checkPendingOrder()` 다음 줄이 바로 `checkTriggers()` 라
`trading:update` 만 잡으면 그 틈에서 뚫립니다.

❌ **마크가격 판정은 못 바꿉니다.** 바꾸면 수동청산 체결가와 TP/SL 발동가까지
같이 바뀌어 부작용이 큽니다.

### ⚠️ 150배는 지금 조용히 125배로 깎입니다

`js/trading.js:96 MAX_LEVERAGE = 125`. `setLeverage(150)` 을 불러도 125 가 됩니다.
**진짜 150배를 만들려면 `openPosition` 을 감싸야 합니다.** 실측으로 잔고 계산까지
한 푼도 안 틀리게 되는 것을 확인했습니다.

### 기존 포지션에 미치는 영향 (0.5% → 0.4%)

**롱은 모든 배율에서 유리합니다.** 청산가가 진입가에서 멀어집니다.
**숏은 4배 이상만 유리하고, 1·2·3배 숏은 아주 조금 불리해집니다.**

| 배율 | 숏 영향 |
|---|---|
| 1배 | 불리 0.149% |
| 2배 | 불리 0.065% |
| 3배 | 불리 0.024% |
| 4배 이상 | 유리 |

**즉시 청산되는 회원이 나올 수 있는 경우** — 숏 3배 이하이면서 현재가가
신규~기존 청산가 사이(폭 0.02~0.15%)에 있을 때만. **롱은 어떤 경우에도 아닙니다.**

**실제 명단은 못 셉니다.** `positions` 표에 RLS 가 걸려 있어 대표만 조회할 수 있습니다.

### ⚠️ 전 종목 0.4% 고정은 큰 금액에서 바이낸스보다 훨씬 후합니다

바이낸스 BTC 는 명목가 30만을 넘으면 0.5% → 0.65% → 1% → 2% 로 올라갑니다.
잔고 10만 × 150배 = 명목가 1,500만이면 바이낸스는 **2%(최대 25배)** 인데 우리는 0.4% 입니다.
**의도한 차이면 그대로 두면 되지만, "바이낸스처럼" 이라는 지시와는 큰 종목에서 어긋납니다.**
