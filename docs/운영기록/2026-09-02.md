# 지표 다음 3개 — 기준선 때문에 한 번 멈췄습니다

차트팀에 StochRSI · ATR · CCI 를 배정하면서 **"기준선 그리는 길이 틀에 없으면
거기서 멈추고 보고하라"** 고 했고, 실제로 없어서 멈췄습니다.

## 차트팀이 확인한 것 (추측 아님, 실제로 돌려봄)

```
define() 에 guides 를 넣으면 → ★true 를 돌려주고 경고 0건인데 저장은 안 됨★
가짜 시리즈에 createPriceLine 을 달아두고 켜봄 → 호출 ★0회★
소스 검색 → createPriceLine 0 · PriceLine 0 · guide 0 · level 0
```

**누가 나중에 `guides:[...]` 를 적으면 지표는 멀쩡히 켜지고 기준선만 없습니다.
오류도 경고도 안 납니다 — 조용한 고장 모양 그대로입니다.**

틀은 `GUIDE_COLOR = "#1D273B"` 를 "눈금·안내선용" 주석과 함께 이미 선언해 뒀는데,
실제 쓰임은 fx 목록 점 배경 한 곳뿐이었습니다. **길을 낼 생각은 했는데 안 낸 상태.**

## PM 결정 4건 (전부 재량, 대표 안 기다림)

| | 결정 | 근거 |
|---|---|---|
| 기준선 | **안 A — 틀 1·5절을 엽니다 (~25줄)** | `chart-oscillators.js:640` `addGuide()` 가 이미 RSI 30/70 · MACD 0선을 그 방식으로 그립니다. 같은 집 안의 정답을 베낍니다 |

**안 B(11절 안에서 우회)를 버린 이유** — 눈에 보이게 틀립니다.
점 2,012개가 기준선 몫으로 실리고, 틀이 눈금색을 거부해 **밝은 지표색으로 기준선을 그려야**
하고, 가격축에 `100` · `−100` 라벨이 붙습니다. 바이낸스·트레이딩뷰 둘 다 안 그럽니다.

**차트팀에 같이 시킨 것** — `guides` 가 조용히 버려지던 것 수정(모르는 칸이 오면 경고),
그리고 **지표를 껐을 때 기준선이 남는지** 브라우저에서 3회 켰다껐다 하고 숫자로 보고.
`removeSeries` 가 `createPriceLine` 을 같이 지우는지 아무도 모릅니다.

## 차트팀이 확인 못 한 것

- **트레이딩뷰 앱 설정 창** — 지표 추가에 회원가입 벽이 떠서 막혔습니다.
  **저희는 로그인하지 않습니다.** 트레이딩뷰 값은 공식 도움말 문서에서 읽은 것입니다
