## 🔴 1. 랭킹 0원 조사 SQL 실행

**대기 시작** 2026-08-24 · **파일** `supabase/조사-랭킹0원-2026-08-24.sql` (읽기 전용)

**상황** — `get_leaderboard` 가 3명 전부 `총자산 100,000 / 수익금 0` 을 돌려줍니다.
같은 화면 채팅에는 오늘 김갱님 거래 7건(합계 -220,579,147원)이 떠 있습니다.

**왜 본부장이 못 푸나** — 랭킹 값은 서버의 `trading_accounts.realized_pnl` 입니다.
비회원 권한으로는 그 표를 못 읽습니다. **초기화된 건지, 손익이 안 쌓이는 건지 못 가립니다.**

**이것 때문에 막힌 일 (2건)**
| 건 | 내용 |
|---|---|
| TL-010 | 랭킹 전원 0원 (P1) |
| — | 주말 계좌 초기화 원인 (8/22부터 3회 보고, 답 없음) |

**대표가 할 일** — 파일을 통째로 Run 하고 **결과 캡처만** 보내주시면 됩니다. 아무것도 안 바뀝니다.

## 🔴 2. 계급 SQL 실행 — 다른 것들의 선행조건

**대기 시작** 2026-08-24 · **파일** `supabase/schema-rank-1000.sql`

**순서를 지켜야 합니다.**

```
1. supabase/schema-rank-1000.sql        ← 계급
2. supabase/회원삭제-2026-08-24.sql      ← 회원 정리
3. supabase/schema-tl-realtime.sql       ← TL 실시간 지급
```

**3번을 1번보다 먼저 돌리면 모든 회원 계급이 무너집니다.**
3번 파일 맨 앞에 자동 확인을 넣어뒀습니다 — `⚠` 가 나오면 멈추면 됩니다.

**이것 때문에 막힌 일 (3건)** — 계급 1000억 체계 / 회원 정리 / TL 실시간 지급

**옛 파일 주의** — `schema-tl-monthly.sql` 은 봉인했습니다. 실수로 Run 해도 아무 일이 없습니다.

## 🟠 3. 로그인한 폰 화면 캡처

**대기 시작** 2026-08-24

**규칙상 본부장은 로그인하지 않습니다.** 그래서 이 화면들을 눈으로 못 봅니다.

```
포지션 표 · 내 자산 · 미체결 주문 · 주문 시트 안 내용
```

**오늘 주문 패널을 하단 시트로 크게 바꿨습니다.** 로그인하면 시트 안에 미체결 주문 카드와
무료충전이 추가돼 내용이 1,233px 보다 길어집니다. 잘리지는 않게 만들었지만 **실제로 못 봤습니다.**

**대표가 할 일** — 폰으로 로그인하고 **아래 매수 버튼을 눌러 시트를 연 캡처 1장.**
