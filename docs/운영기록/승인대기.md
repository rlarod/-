## 🔴 A1. 테스트에 박힌 "레퍼런스 실측값"을 바꿔도 되나요

**대기 시작** 2026-08-21 15:50 · **막힌 일: 최소 4건**

### 무슨 상황인가

`tests/top-panel.test.js` 가 거래 화면 골격을 **숫자로 못박고** 있습니다.
본부장이 직접 코드로 확인했습니다.

| 강제하는 것 | 값 | 위치 |
|---|---|---|
| 차트 폭 비율 | **42.4% ±1.5** | 1101행 |
| 호가창 폭 비율 | **16.8% ±1.5** | 1102행 |
| 주문창 폭 비율 | **16.0% ±1.5** | 1103행 |
| 채팅 폭 | **23% 고정** | 1092행 |
| 거래 행 높이 | **≥1120px** | 1124행 |

바이낸스는 **차트 62.7 / 호가 16.7 / 주문 20.9** 입니다.

### ⭐ 차이의 진짜 원인 — 채팅 칼럼입니다

```
우리    차트 42.4  호가 16.8  주문 16.0  + 채팅 23   = 98.2
바이낸스 차트 62.7  호가 16.7  주문 20.9  + 채팅 없음 = 100.3
```

**호가창과 주문창은 이미 바이낸스와 거의 같습니다.**
차트만 20%p 좁은데, **그 20%p가 정확히 채팅 칼럼입니다.**

그런데 **채팅(실시간 익절/손절 알림 피드)은 대표가 지키라고 하신 TL 개성**입니다.

### 그래서 진짜 질문은 이겁니다

> **거래 화면에서 채팅을 뺄 것인가, 아니면 차트가 좁은 걸 받아들일 것인가.**

세 갈래가 있습니다.

| 안 | 내용 | 잃는 것 | 얻는 것 |
|---|---|---|---|
| **가** | 채팅을 거래 화면에서 빼고 별도 화면·접이식으로 | 알림 피드가 항상 보이던 것 | 차트가 바이낸스급으로 넓어짐 |
| **나** | 채팅 유지, 차트 비율은 그대로 | 바이낸스 밀도 | TL 개성 그대로 |
| **다** | 채팅을 좁히거나(23%→15%) 접었다 폈다 | 조금씩 | 절충 |

**답할 것** — "가" / "나" / "다" / "테스트 숫자는 못 바꿔"

> ⚠️ 어느 쪽이든 **테스트 숫자를 같이 고쳐야** 합니다. 그 숫자는 개미톡을

### 본부장 추천 — 둘을 나눈다

| | 지금 | 제안 |
|---|---|---|
| ⚡ 알림 | 오른쪽 세로 칸 23% 에 갇힘 | **위/아래 얇은 가로 띠로 흐르게** (40~50px) |
| 💬 대화 | 같은 칸에 섞임 | **접이식** — 버튼으로 열고 닫기 |

**결과**: 차트 42% → 62%(바이낸스급) + 알림은 오히려 더 눈에 띔 + 대화도 유지

### 다른 안

| 안 | 차트 | 알림 | 깔끔함 |
|---|---|---|---|
| **알림 띠 + 대화 접이식** (추천) | 62% | 항상 보임 | ★★★ |
| 채팅 통째로 포지션 아래 | 62% | 스크롤 내려야 보임 | ★★★ |
| 채팅 칸 좁히기 (23%→14%) | 51% | 항상 보임 | ★★ |
