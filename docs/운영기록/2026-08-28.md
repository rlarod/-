## 🔴 채팅 루프는 **자작극이었습니다** (조사팀, 확신도 확실)

**첫 끊김이 무엇이든 상관없습니다. 재연결 코드가 스스로 끊김을 만들어 냅니다.**

```js
// js/chat.js:162
if (channel) { client.removeChannel(channel); }
```

**`removeChannel` 이 그 채널의 상태 콜백을 같은 밀리초에 `CLOSED` 로 부릅니다.**

### 실증 — 같은 client 로 직접 확인

```
[54336, "SUBSCRIBED"]
[58282, "--calling removeChannel--"]
[58283, "CLOSED"]          ← 1ms
```

### 고리

```
재연결 타이머 발화 → reconnectTimer=null(196) → subscribeRealtime
  → removeChannel(162) → 옛 채널 CLOSED(180) → scheduleReconnect(181) → 1000ms 예약
  → 새 채널 SUBSCRIBED → attempts>0 이라 loadRecent(175) → attempts=0
  → 1000ms 뒤 처음으로
```

**`reconnectTimer` 가 바로 앞 196행에서 비워진 뒤라 191행 중복 방지가 안 걸립니다.**
**`SUBSCRIBED` 가 매번 성공해도 `attempts` 가 0 으로 리셋돼 대기시간이 안 늡니다.**
