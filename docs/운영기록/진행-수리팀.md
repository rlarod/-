### P1 핵심 (한 줄)

**체결 스트림 `@trade` 는 바이낸스 `/public` 경로에만 있는데
`js/config.js` 가 만드는 접속 주소는 `/market` 경로라, 이름만 넣고 데이터는 한 건도 안 옵니다.**
바이낸스가 없는 스트림 이름에 오류를 안 내고 연결을 유지해서 조용히 고장난 것입니다.

같은 시각 실측:

```
/market  … btcusdt@trade   → 15초에 0건
/public  … btcusdt@trade   →  8초에 737건
/market  … btcusdt@aggTrade→  8초에 234건
```

사이트 실측(1920px, 비로그인, 10초): `trade:tick` **0회** / `orderbook:update` 21회 /
`kline:update` 32회 / 패널 높이 575.75px / 목록 0줄 / **콘솔 오류 0건**

**파생 — 더 큰 것:** 5초 간격에서 12초 측정 → `kline:update` **0회**, `price:update` **0회**.
`js/trading.js` 는 `price:update` 하나로 손익·청산을 돌리므로 **손익이 멈추고 강제청산 판정이 안 돕니다.**
