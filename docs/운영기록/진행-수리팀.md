준비안은 "TL-004 를 고치면 압력 바도 같이 살아난다"였는데, **실측 결과 아니었습니다.**

체결이 살아난 직후 다시 재보니 압력 바가 **여전히 `매수 50% / 매도 50%`** 였습니다.
이유는 처음과 다릅니다.

- 전(前): 체결이 0건이라 `buyIntensity + sellIntensity == 0` → 대체값 50 이 나옴
- 후(後): 체결이 초당 45건씩 들어오는데, `js/market-war.js` 의 강도는 체결 1건마다
  **최소 10 씩 오르고**(FREQUENCY_GAIN) **초당 4.5 밖에 안 내려갑니다**(INTENSITY_DECAY_PER_SEC).
  그래서 매수·매도 강도가 **둘 다 상한 100 에 붙어버립니다.**
  실측: `mw-buy-pct` **100%** / `mw-sell-pct` **98~100%** 고정, HUD `BUY EXTREME ASSAULT`.
  **상한에 붙은 두 값의 비율은 언제나 50:50 입니다.**

즉 강도는 "얼마나 격렬한가"를 나타내는 **전쟁터 연출값**이지, "어느 쪽이 우세한가"를
나타내는 값이 아닙니다. 압력 바가 그걸 그대로 쓴 것이 애초에 잘못이었습니다.

**대표가 제일 급하다고 한 것이 1번(압력 바)** 이라, 여기서 멈추지 않고 표시 쪽을 고쳤습니다.

`js/order-pressure-bar.js` (수정 금지 12개 아님, 표시 전용 모듈)

### ① TL-003 — importmap 만 넣으면 안 고쳐집니다 (결함이 두 개였음)

준비안은 importmap 추가만 적혀 있었는데, **두 번째 결함**이 있었습니다.
`SkeletonUtils.js`(r160)는 `SkeletonUtils` 라는 이름을 **내보내지 않습니다**
(실제 export 는 `retarget` / `retargetClip` / `clone` 셋뿐 — CDN 파일 원문 확인).
그래서 `import { SkeletonUtils }` 는 importmap 을 넣어도 **SyntaxError 로 죽고**,
그 모듈 전체가 멈춰 `window.GLTFLoader` 까지 같이 안 만들어집니다.
→ `import * as SkeletonUtils` 로 바꿔야 합니다.

**그리고 "three 두 벌" 위험은 회피했습니다(대표·본부장이 반드시 확인하라고 한 것).**
importmap 을 `three.module.js` 로 걸면 두 벌이 됩니다. 대신 **이미 로드된 전역 THREE 를
그대로 다시 내보내는 로컬 shim** 을 가리키게 했습니다.

브라우저 실측으로 두 벌이 아님을 증명:
```
shim 의 Mesh === window.THREE.Mesh                         -> true
GLTFLoader 가 만든 clone instanceof window.THREE.Object3D  -> true
네트워크에 three.module.js 요청                             -> 0건 (three.min.js 만 1건)
```

### ② TL-001 — 끊는 지점이 430px 이 아니라 700px 이어야 합니다

준비안은 `@media (max-width:430px)` 였는데, 실측해 보니 **펀딩비는 700px 까지 안 보입니다.**

360 X  375 X  390 X  430 X  520 X  600 X  700 X | 730 O  768 O
