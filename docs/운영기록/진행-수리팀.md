준비안은 "TL-004 를 고치면 압력 바도 같이 살아난다"였는데, **실측 결과 아니었습니다.**

체결이 살아난 직후 다시 재보니 압력 바가 **여전히 `매수 50% / 매도 50%`** 였습니다.
이유는 처음과 다릅니다.

- 전(前): 체결이 0건이라 `buyIntensity + sellIntensity == 0` → 대체값 50 이 나옴
- 후(後): 체결이 초당 45건씩 들어오는데, `js/market-war.js` 의 강도는 체결 1건마다
  **최소 10 씩 오르고**(FREQUENCY_GAIN) **초당 4.5 밖에 안 내려갑니다**(INTENSITY_DECAY_PER_SEC).
  그래서 매수·매도 강도가 **둘 다 상한 100 에 붙어버립니다.**
  실측: `mw-buy-pct` **100%** / `mw-sell-pct` **98~100%** 고정, HUD `BUY EXTREME ASSAULT`.
  **상한에 붙은 두 값의 비율은 언제나 50:50 입니다.**

즉 강도는 "얼마나 격렬한가"를 나타내는 **전쟁터 연출값**이지, "어느 쪽이 우세한가"를
나타내는 값이 아닙니다. 압력 바가 그걸 그대로 쓴 것이 애초에 잘못이었습니다.

**대표가 제일 급하다고 한 것이 1번(압력 바)** 이라, 여기서 멈추지 않고 표시 쪽을 고쳤습니다.

`js/order-pressure-bar.js` (수정 금지 12개 아님, 표시 전용 모듈)
