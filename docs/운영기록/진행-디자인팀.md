### 걸렸던 것 (다음 회차 참고)

`agent-browser` 를 세션 이름 없이 쓰면 **명령마다 다른 탭에 붙습니다.**
바이낸스를 열고 잰 줄 알았는데 localhost 값이 나온 일이 세 번 있었습니다.
→ **`--session <이름>` 을 항상 붙입니다.** (`--session bn`, `--session tl`)
`batch` 는 경로를 `/tmp/...` 로 못 받습니다. 윈도우 경로를 씁니다.
긴 스크립트는 `eval -b <base64>` 로 넘깁니다 (batch 안에서는 따옴표가 깨집니다).
