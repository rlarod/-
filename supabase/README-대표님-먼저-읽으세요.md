  아무것도 바뀌지 않습니다. 숫자를 보고 맞다 싶으실 때 나머지를 돌리시면 됩니다.

## 3. 열 필요 없는 파일 — 눌러도 아무 일 없습니다

실수로 Run 하셔도 안전하도록 **미리 막아 두었습니다.**

| 파일 | 왜 막았나 |
|---|---|
| `supabase/cleanup-test-data.sql` | 회원 **전원 삭제** 파일. 지우는 부분을 막아 뒀습니다 |
| `supabase/schema-tl-monthly.sql` | TL 을 **한 달에 한 번** 주던 옛 방식. 실시간으로 바뀌었습니다 |
| `supabase/schema-tl-hotdeal.sql` | 상점은 살아 있고, **옛 TL 계산 부분만** 막았습니다 |
| `supabase/schema-tl-balance-fix.sql` | TL 잔액 표시 부분을 막았습니다. 지금은 3번 파일이 그 일을 합니다 |
| `supabase/schema-rank-assets.sql` | **계급을 매기던 옛 방식.** 지금은 1번 파일이 그 일을 합니다 |
| `supabase/schema-rank-badges.sql` | **계급 점수를 TL 로 매기던 더 옛 방식.** 계급장은 그대로 보입니다 |

이 파일들은 **기록으로 남겨 둔 것**입니다. 지우지 않았습니다.

> **계급 관련 두 파일을 왜 막았나**
> 1번 파일(`schema-rank-1000.sql`)을 돌린 뒤에 저 두 파일을 실수로 누르면,
> 회원 계급이 전부 **옛 기준으로 조용히 되돌아갑니다.**
> 오류도 안 나고 화면도 멀쩡해서 아무도 눈치채지 못합니다.
> 그래서 미리 막아 뒀습니다. 이제 눌러도 계급은 안 바뀝니다.
