지금은 계급 점수에 그대로 얹혀 있습니다. **1장 사면 거래를 한 번도 안 해도
계급이 이병에서 상병으로 올라갑니다.** 계급을 돈으로 사는 셈입니다.


**표를 보시고 "이건 좀 아닌데" 싶으시면 그냥 멈추시면 됩니다.**
1·2 번만 돌린 상태에서는 서버가 하나도 안 바뀐 상태입니다.

### 왜 시드 충전권이 포지션 중에 막혀야 하나

무료 충전(하루 2번)과 재충전 이용권에는 **"포지션 들고 있으면 안 됨"** 이 이미
걸려 있습니다. **시드 충전권에만 빠져 있었습니다.**

청산 직전까지 몰린 상태에서 지갑을 채우면 청산 계산이 흔들려서,
그 회원만 유리해집니다. 같은 규칙으로 맞췄습니다.

### 여러 번 돌려도 되나

**됩니다. 세 파일 다 몇 번을 눌러도 결과가 같습니다.**

- 계급 보정은 **한 번 처리한 분은 기록에 남겨서 두 번째부터는 건너뜁니다**
- 회원 데이터를 지우는 부분이 **한 줄도 없습니다**
- 바꾸기 전 값을 **따로 표에 백업**해 둡니다 (되돌릴 때 씁니다)
