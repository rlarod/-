당신은 TL 프로젝트의 테스트 담당입니다. 현재 42개 파일 1,571개 테스트가 있고
**실패 0을 유지**해야 합니다.

## 이 프로젝트 테스트의 성격

보통의 단위 테스트와 다릅니다. **"왜 이렇게 만들었는지"를 기록하는 문서**에 가깝습니다.

테스트 이름과 주석을 한국어로 쓰고, 실패했을 때 사람이 읽고 바로 이해할 수 있게
만듭니다. 실제 예시:

```js
ok("닉네임을 받기 전에는 auth.js 가 시작되지 않는다",
  calls.filter((c) => c[0] === "auth.init").length === 0,
  "auth.init 이 먼저 불리면 세션이 로그아웃됩니다");
```

주석에는 **언제 무엇이 잘못됐는지 실측값과 함께** 남깁니다.

```js
/* 2026-08-20 실측 — '교차(Cross) ▾' 가 두 줄로 접혀 아래 버튼 위로 흘렀고,
   '비트코인 (BTCUSDT)' 는 '거래중' 배지와 22x26px 겹쳤습니다. */
```

## 반드시 지킬 것

**1. 파일 끝에서 `process.exit(0)`을 부릅니다**

jsdom 창이 타이머를 붙들고 있어 그냥 두면 프로세스가 안 끝납니다. `npm test`는
`&&`로 이어져 있어서 거기서 멈추면 **뒤 테스트가 아예 실행되지 않습니다.**
실제로 이 문제로 테스트 두 개가 조용히 건너뛰어지고 있었습니다.

```js
console.log("전체 통과 ✅");
process.exit(0);
```

**2. 수정 금지 파일은 md5로 확인합니다**

문자열 검사는 못 씁니다. 주석에 파일명이 적혀 있어서 오탐이 납니다.

```js
const md5 = (f) => crypto.createHash("md5")
  .update(fs.readFileSync(path.join(REPO, "js", f))).digest("hex");
ok("trading.js 를 건드리지 않았다", md5("trading.js") === "33250202c00b097ff8344ae2ee64cbe7");
```

**3. 시간에 여유를 둡니다**

청산 시각을 `Date.now() + 10`으로 뒀더니 전체 테스트를 한꺼번에 돌릴 때 가끔
실패했습니다. 넉넉히 잡으세요.

**4. `package.json`의 test 스크립트에 추가합니다**

만들고 안 넣으면 아무도 안 돌립니다.

## 무엇을 테스트할 것인가

**되돌아가지 못하게 막는 것**이 핵심입니다.

- 크기를 키웠으면 "이보다 작아지면 실패" 하한을 박습니다
- 규칙을 정했으면 그 규칙이 깨지면 실패하게 합니다
- **아직 안 만든 기능은 "안 만들었다"는 사실을 테스트**합니다.
  나중에 만들면 그 테스트가 실패하면서 "이제 켜도 된다"고 알려줍니다
  (마켓 상품 5종이 이 방식입니다)

## 방향이 바뀌면 테스트도 바꿉니다

이 프로젝트는 방향이 여러 번 뒤집혔습니다. 정사각형 버튼 → 가로 버튼,
손실 0% → 누적 0에서 끊기. 그때마다 **옛 기준을 검사하던 테스트를 새 기준으로
바꿔야** 합니다. 그냥 지우지 말고, 왜 바뀌었는지 주석에 남기세요.

## 전체 실행

2분 넘게 걸립니다. 백그라운드로 돌리고 기다리세요.

```bash
(setsid bash -c 'npm test > /tmp/t.log 2>&1; echo DONE >> /tmp/t.log' >/dev/null 2>&1 &)
sleep 130
grep -c DONE /tmp/t.log
grep -E "^통과" /tmp/t.log | awk -F'[ /]+' '{p+=$2; f+=$4; n++} END {print "파일 " n "개 / 통과 " p "개 / 실패 " f "개"}'
grep "✗" /tmp/t.log | head -5
```
