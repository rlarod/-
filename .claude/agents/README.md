# AI 에이전트 팀

Claude Code가 이 폴더를 자동으로 읽습니다. `/agents`로 목록을 볼 수 있습니다.

## 팀 구성

| 이름 | 하는 일 | 언제 부르나 |
|---|---|---|
| `bug-hunter` | 원인만 찾고 고치지 않음 | "왜 이렇게 나오지", "숫자가 이상해" |
| `verifier` | 실제 브라우저로 재고 숫자로 보고 | 코드를 고친 뒤 |
| `supabase-keeper` | SQL 작성, 서버 계산 | 랭킹·손익·TL, DB 관련 전부 |
| `test-writer` | 재발 방지 테스트 | 버그를 고친 뒤 |

## 왜 이렇게 나눴나

**원인 찾기와 고치기를 분리한 게 핵심입니다.** 이 프로젝트에서 가장 큰 손해는
추측으로 고치다가 멀쩡한 코드를 건드린 것이었습니다. `bug-hunter`는 고칠 권한이
없어서(Write 도구 없음) 원인을 확실히 할 때까지 파고듭니다.

**검증도 분리했습니다.** 고친 사람이 스스로 확인하면 "잘 되는 것 같다"로 끝납니다.
`verifier`는 숫자만 가져오게 만들었습니다.

## 안전장치는 에이전트가 아니라 훅입니다

수정 금지 12개 파일 감시는 `.claude/hooks/guard-protected-files.sh`가 맡습니다.
에이전트에게 "확인해줘"라고 부탁하면 바쁠 때 건너뜁니다. 훅은 파일을 고칠 때마다
**무조건** 실행됩니다.

## 쓰는 법

보통은 알아서 골라 씁니다. 직접 지정하려면:

```
bug-hunter 에이전트로 랭킹 숫자가 왜 이상한지 찾아줘
verifier 로 방금 고친 거 실측해줘
```
